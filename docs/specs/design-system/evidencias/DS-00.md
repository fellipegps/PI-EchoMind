## Contraste — método e resultados reais

Entradas: HEX opacos aprovados na tabela DS-00 v1.0. Cálculo executado em JavaScript nesta sessão, diretamente sobre esses valores, sem estimar cor por imagem ou alegar contraste do CSS renderizado.

Método: normalizar cada canal sRGB para 0–1; linearizar com limiar 0,04045; calcular luminância ponderada; dividir a luminância maior acrescida de 0,05 pela menor acrescida de 0,05. Referências do método: [luminância relativa](https://www.w3.org/TR/WCAG22/#dfn-relative-luminance) e [razão de contraste](https://www.w3.org/TR/WCAG22/#dfn-contrast-ratio), consultadas em 11/10/2026.

Trecho reproduzível do cálculo utilizado; os pares de entrada estão na tabela seguinte:

```js
function luminancia(hex) {
  const [r, g, b] = hex.slice(1).match(/../g)
    .map(v => parseInt(v, 16) / 255)
    .map(s => s <= 0.04045
      ? s / 12.92
      : ((s + 0.055) / 1.055) ** 2.4);
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}
function contraste(texto, fundo) {
  const a = luminancia(texto), b = luminancia(fundo);
  return (Math.max(a, b) + 0.05) / (Math.min(a, b) + 0.05);
}
// Comparar a razão sem arredondar com 4.5; arredondar só a exibição.
contraste("#DC2626", "#F1F5F9"); // 4.408332924561144
```

Controles de sanidade executados: preto/branco = **21:1**; mesma cor = **1:1**. Resultados exibidos com quatro casas decimais; decisões usam o valor sem arredondamento. A meta contratual para texto de interface é 4,5:1.
